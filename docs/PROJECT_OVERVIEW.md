# 项目概况

| 项目 | 内容 |
| --- | --- |
| 名称 | Roboheart · 涌现 |
| 形式 | Game Jam 团队游戏 |
| 类型 | 2D 叙事解谜 |
| 视角与操作 | 横向场景探索，键盘与鼠标交互 |
| 内容 | 序章与三个章节 |
| 角色 | 机器人 R-0 |
| 本人的角色 | 主程序 |
| 技术 | Unity 6000.6.0f1、C#、Unity 2D、IMGUI |

## 玩法循环

探索房间，观察线索，收集和使用道具，解决机关，再通过灵魂碎片与章节回忆推进剧情。游戏包含配对、排列、旋钮以及拖拽旋转等解谜交互。

章节谜题与剧情有先后关系。库存、机关和剧情关键阶段共同保存，玩家可从有效进度继续。
