## 游戏简介

《Roboheart》是一款 2D 叙事解谜游戏。残次品机器人 R-0 在主人林意外离世后重新启动，为完成最后的指令踏上寻找灵魂碎片的旅程。玩家将在旧日生活的场景中探索、解谜、收集记忆，看着一个原本不懂情感的机器人，在回忆中逐渐“涌现”出属于自己的心。

## 玩法循环

探索房间，观察线索，收集和使用道具，解决机关，再通过灵魂碎片与章节回忆推进剧情。游戏包含配对、排列、旋钮以及拖拽旋转等解谜交互。

库存、机关和剧情关键阶段共同保存，玩家可从有效进度继续。程序设计见 [技术介绍](TECHNICAL_OVERVIEW.md)，具体成员分工见 [团队署名](../CREDITS.md)。
