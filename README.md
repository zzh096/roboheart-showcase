**Unity 2D 叙事解谜游戏 · Game Jam 团队项目 · 主程序作品展示**

## 程序设计

- **统一交互与道具使用**：通过一致的输入入口处理目标选择、查看、拾取和机关操作。
- **进度恢复**：将库存、物品收集、机关与剧情阶段共同纳入自动存档，支持中途继续游戏。
- **解谜小游戏**：动物配对、透卡对齐、拖拽旋转修补等交互，并将有效进度接入章节状态。
- **剧情演出**：配置驱动的文本和选项、章节 CG、人物图层淡出、暂停与长按跳过。

技术栈：**Unity 6000.6.0f1 / C# / Unity 2D / IMGUI**。

## 操作

| 输入 | 行为 |
| --- | --- |
| A / D 或左右方向键 | 移动 |
| 空格 | 跳跃；普通对白补全 / 继续 |
| E | 交互；普通对白继续 |
| 鼠标左键 | 拾取、查看、操作机关、选择物品栏 |
| F | 使用选中的道具 |
| Q | 查看物体 |
| 1–5 / 滚轮 | 切换道具 |
| 拖动；相关小游戏中滚轮 / 右键 | 移动、旋转道具 |
| Esc | 暂停并查看完整操作提示 |
| CG 中长按 Q 约 2 秒 | 跳过当前整段 CG |

游戏自动保存有效进度；“继续游戏”恢复最近存档，“开始游戏”重新开始并覆盖自动存档槽。CG 对白自动播放，完整显示后保留阅读时间。
